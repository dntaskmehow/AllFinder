AUTHORIZED LAB EXAMPLEBASH
# Make the script executable
chmod +x allfinder.sh

# Passive discovery
./allfinder.sh -d example.com

# Optional active enumeration
./allfinder.sh -d example.com -w subdomains.txt \
  -o ./authorized-results

!

SCOPE IS PART OF THE RESULT

Know the boundary.

AllFinder may send passive, DNS, HTTP, and wordlist-driven requests through several external tools. Run it only against domains you own or have explicit written permission to assess, and avoid active enumeration unless it is approved.

Discovery results, live-host metadata, CNAME mappings, and takeover-oriented outputs require human review and may contain sensitive infrastructure information.
